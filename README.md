## What is Filos?
Filos is a file manager designed with the modern iOS jailbreaking space in mind. Its objective is to offer an alternative to popular file managers, such as Filza. The difference is that this file manager doesn't require any license and is fully open-source!

Currently, Filos is in a very preliminary state. There's a lot of features from Filza that aren't currently available here (e.g. FTP, Assets.car editing, data editing). Stability cannot be guaranteed, so **use at your own risk!** Human-written pull requests are encouraged!

## Installation
- You will need a device running iOS/iPadOS 15.0 or later, as well as a sideloading method of your choice.

## Features
- Operations
   - Import file
   - Create file/folder/symlink
   - Quick look/copy/share/delete
   - Get info (file properties, permissions)
   - Extract archive
   - Compress folder
- Editing
   - Plist editor
   - Text editor
- QoL
   - Search (in directory)
   - Filter (Name, Date, Type, Size)
   - Go to directory
   - Favorites
   - Custom SBX token
