## What is Filos?
Filos has been built around FileManager and Swift/SwiftUI to bring you a powerful file browsing experience similar to those of popular file managers, such as Filza. The difference is that this file manager is designed with modern devices and exploits/jbing in mind, which is why you'll see features that you wouldn't normally see from a file manager.

At the moment, Filos does have some missing features that you'd find in Filza and other popular managers (such as FTP). Human-written pull requests are encouraged!

## Installation
- You will need a device running iOS/iPadOS 16.0 or later, as well as a sideloading method of your choice.

## Features
- Operations
   - Import file
   - Create file/folder/symlink
   - Quick look/copy/share/delete
   - Get info (file properties, permissions)
   - Extract archive
   - Compress folder
- Editing
   - Plist editor
   - Text editor
- QoL
   - Search (in directory)
   - Filter (Name, Date, Type, Size)
   - Go to directory
   - Favorites
   - Custom SBX token
